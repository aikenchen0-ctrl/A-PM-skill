# 原文机制卡与可用操作

卡片编号便于方案追溯。下表中的“原文节点”指随技能携带的 [source-index.json](source-index.json)，按 XML 文档顺序编号。节点范围是资料位置，不是研究证据评级。全部产品操作是迁移假设；每次只选与问题有关的条目。

这里的18张是主题级归并，不是18个独立机制。具体机制、模型、条件、操作和原文覆盖处置见[细粒度知识目录](mechanism-index.md)。一个节点范围内可能有多个不同机制，不能因范围被引用就认为它们在本表已逐项表达；具体设计应读取对应细粒度条目和必要的原文上下文，不能从大类名称直接推导其适用性。

## 使用约束

上表选择条件是分析线索，不是证明必要且充分。原文含错词、残句、重复和研究主张；参见[来源与纠错](source-audit.md)。低自尊、表情、语速等不能据此推断个人的可操控性或诚实程度。

产品故障、价格不合适、服务不可用也可解释转化下降，不必总找心理效应。调用机制的目的，是改变设计选择及验证方式，而不是给现象补一个术语。
